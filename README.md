# Kernel Mobile v2

[![Hippocratic License HL3-LAW-MIL-SV](https://img.shields.io/static/v1?label=Hippocratic%20License&message=HL3-LAW-MIL-SV&labelColor=5e2751&color=bc8c3d)](https://firstdonoharm.dev/version/3/0/law-mil-sv.html)

Mobile companion app for the kernel-evolving AI agent — chat, monitor, and control your agent from your phone.

Built with **React Native + Expo**.

## Features

- 💬 **Chat** — Direct chat with the kernel-evolving agent (matches desktop UI)
- 🧬 **Agent list & profiles** — Manage connected agents
- 🔌 **QR device pairing** — Pair your phone to your agent
- 🗄️ **Local persistence** — SQLite storage for messages and settings
- 🎤 **Voice** — Voice input and TTS output
- ⚙️ **Settings** — Providers, models, themes, and more
